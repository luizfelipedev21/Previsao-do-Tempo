Funcionalidade:

**Busca por Cidade:** Pesquisa qualquer localidade do mundo.
 
 **Métricas Climáticas:** Exibe temperatura atual, umidade do ar, velocidade do vento e condição do tempo (céu limpo, chuva, tempestade, etc.).
 
 **Fundo Dinâmico em HD:** O plano de fundo da aplicação muda automaticamente para uma foto real da cidade pesquisada.

**Alertas Personalizados:** Tratamento de erros amigável (cidade não encontrada ou campo vazio) utilizando modais estilizados.
 
 **Design Glassmorphism:** Interface moderna adaptada para dispositivos móveis e desktop.
